# Simulador de Juego de Dados

## ¿Qué es?
Es un programa interactivo desarrollado en Python 3 que simula el lanzamiento
aleatorio de dos dados convencionales de seis caras contra un puntaje meta
establecido por el usuario.

## ¿Para qué sirve?
Permite modelar eventos probabilísticos simples y evaluar condiciones de victoria o
derrota mediante estructuras condicionales en consola.

## ¿Cómo se usa?
1. Abrir el entorno de desarrollo (Thonny, VS Code o terminal).
2. Ejecutar el script principal:
`python juego_dados.py` (o `proyecto_final.py`)
3. Ingresar el nombre del jugador cuando la consola lo solicite.
4. Ingresar un número entero como meta a superar (entre 2 y 12).
5. El sistema calcula la suma aleatoria e imprime el resultado final indicando si se
superó el objetivo.
